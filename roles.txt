O PokeTeamGuess é um jogo onde o objetivo é quem acerta primeiro o time do adversario
Os dois jogadors jogam no mesmo computador

Cada rodada do jogo o jogador chuta um pokemon e recebe as seguintes informacoes
1. Quais dos pokemons do oponente tem o mesmo time primario que aquele pokemon
2. Quais dos pokemons do oponente tem o mesmo time primario que aquele pokemon
3. Se a geracao do pokemon adivinhado é maior, menor ou igual a geracao atual
3. Se a cor daquele pokemon listada na pokedex é igual a cor de algum dos pokemons do time do oponente
5. Se a altura do pokemon é maior, menor ou igual a algum dos pokemons do oponente
6. Se o peso do pokemon é maior, menor ou igual a algum dos pokemons do oponente
7. Se o pokemon adivinhado é o mesmo que um dois pokemons do oponente

Caso algum dos jogadores acerte algum pokemon ele joga novamente

Caso algum dos jogadores acerte todos os pokemons, o jogador adversario tera uma rodada extra
para tentar um empate (ainda sendo valido a regra se acertar um pokemon joga novamente)

O jogo escolhe alietoriamente o jogador que começa chutando

SOBRE SISTEMA
e obrigatorio um usuario `logado`, as informacoes desse usuario ficam guardadas na cash do navegador, 
assim tendo a diferenca entre dois jogadores

Jogador Principal = dono da "conta" no computador
Jogador Convidado = o outro jogador

O jogador principal tera guardado o nome, o historico de partidas, um sistema de levels e xp e o icone escolhido

O sistemas de level funciona da seguinte forma: do level 1 ao 2 sao nessessario 100 de xp, cada level seguinte a quantidade necessario de xp dobra
Cada vitorio gera 20 de xp e cada empate gera 10 de xp, derrotas ou desistencias n geram xp

O sistema tera no total x telas, e todas elas usam como base o componente de pokedex em ./componetes/pokedex, tendo uma coluna esquerda e uma coluna direita


REGISTO/EDITAR PERFIL ========================
-> Coluna esquerda: "Selecione seu inicial"
É escolhido uma foto de perfil que são 001P (Bulbasauro), 002P (Charmander), 003P (Squertle), essas fotos estao em ./assets/player

-> Coluna esquerda: "Digite seu nome"
O jogador insere o nome e cria a conta, caso ele n tenha conta essa tela tem um botao criar perfil, caso ele tenha há os botoes, editar perfil, cancelar e deletar perfil
Caso o usuario escolha deletar o perfil há um modal de confirmação
Aqui tmb há um pequeno texto informando que as informacoes da conta sao salvas na cash do navedador

HOME ===============
-> Coluna esquerda: "Historico de partidas"
Historico de partidas do usuario em uma tabela (usando tags TABLE/TH/TR/TD), onde o usuario consegue ver o historico e excluir uma partida do historico

-> Coluna direita: "Perfil do jogador"
informacoes do perfil do jogador, assim como os botoes de editar perfil e iniciar partida local

SELECAO DE TIME (Jogador Princial) ===============
-> Coluna esquerda: "Selecione seu time"
Local para selecao de time usando os componentes ./componentes/teamSelector e ./componentes/pokemonList

-> Coluna direita: "Time selecionado"
Nome do usuario e foto de perfil, e botao de proximo

SELECAO DE TIME (Jogador Convidado) ===============
-> Coluna esquerda: "Selecione seu time"
Local para selecao de time usando os componentes ./componentes/teamSelector e ./componentes/pokemonList

-> Coluna direita: "Time selecionado"
Campo para inserir nome do jogador, a foto do jogador é escolhida altomaticamente com base na foto do Jogador Princial (se o jogador 
principal escolheu 001P a foto do convidado é 002P, se o principal escolheu 002P a foto do convidade é 003P, e se o principal escolheu 
003P a foto do convidado é 001P)
Há um botao de iniciar partida


TELA DE PATIDA ===========================
Ao abrir essa tela tem um modal disendo quem começa

-> Coluna esquerda: "Campos de adivinhacao"
lista com pokemons do oponente e informacoes que ja sabemos (usar OL/UL/LI)
campo para adivinhacao
Essa parte da tela reflete o turno do jogador atual (sendo ele convidado/principal) e as informacoes dela devem ser guardadas na cash

-> Coluna direita: "Controle de Turnos"
Painel com foto do jogador principal e jogador secundario, com um destaque maior do jogador do turno atual com direito a uma animacaozinha
Placar com quantos pokemons cada jogador ja acertou
Indicador de pokemons ja chutados
Botao de desistir da partida
